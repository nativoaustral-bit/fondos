Importar y Exportar Catálogo (.xlsx)

Actualiza datos de entidades, programas y convocatorias sin tocar el código. La plataforma utiliza Microsoft Excel (.xlsx) como contrato de datos.

1. Descargar base o plantilla

Descarga la base vigente para investigar y actualizar datos con el chat de investigación, o una plantilla limpia con el esquema estándar.

Exportar base vigente (v{{ config.version_catalogo }}) ↓ Descargar plantilla canónica vacía (.xlsx) ↓

2. Subir archivo actualizado

Sube el archivo Excel modificado. El sistema generará una previsualización de diferencias detallada antes de realizar cualquier cambio en la base de datos.

📋 Convenciones del Contrato Excel (.xlsx)

  • Actualización por ID: No modifiques los identificadores existentes (entidad_id, instrumento_id, convocatoria_id).
  • HEREDAR: Puedes escribir HEREDAR en convocatorias para adoptar automáticamente el valor del instrumento padre sin duplicar texto.
  • __BORRAR__: Escribe __BORRAR__ en una celda si deseas vaciar expresamente un campo opcional existente.
  • Celdas vacías: Al actualizar un registro existente, dejar una celda vacía conserva el valor que ya tiene en la base de datos.
  • Verificación independiente: Las columnas terminadas en _verificado_en solo deben actualizarse cuando efectivamente comprobaste ese dato en la fuente oficial.
